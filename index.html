Design System

A framework-agnostic foundation — color, Fellix typography, spacing, and a reusable component library — traced to the Sept 2025 Employer Brand Guidelines and built for any product surface, not just careers/hiring.

Color

The primary palette anchors every UI surface. The expressive palette is reserved for data visualization, illustration, and accenting — not for primary buttons or body text.

Primary palette

Expressive palette

Usage rule (from brand guide): Dark Blue, Blue, and Light Blue may only sit on each other or on White — never on Black. There is no black in this system's neutral scale for that reason; use Ink 900 as the darkest value instead.

Semantic tokens

Product surfaces should reference semantic tokens, not raw palette values — it keeps theming and future rebrands to a one-line change.

Typography

Fellix is the system's only typeface — airy, geometric, round, bold, friendly, timeless, warm. Seven weights are loaded; four "pairing formulas" from the brand guide define which weights may appear together.

Casing

  • Sentence case for headlines, subheads, and body copy.
  • Title Case for product names and taglines only.
  • UPPERCASE is allowed only for short call-outs — CTAs, tags, pricing.
  • Never set a full headline or paragraph in all caps — it hurts legibility.

Alignment

Type is always left-aligned and horizontal. Never center, right-align, justify, or rotate text — and keep at least a ~35% size difference between a headline and the body copy beneath it so the hierarchy reads at a glance.

Spacing & layout

An 4px-based spacing scale keeps rhythm consistent across dense UI and generous marketing layouts alike.

Radius & elevation

Fellix reads as round and friendly, so the system defaults to generous corner radii — pill-shaped buttons and tags, 16px cards.

Iconography

Two icon families cover the system: outlined for navigation and secondary actions, filled for emphasis and status. Both are drawn on a consistent stroke weight and grid.

Do
  • Keep stroke weight consistent within a composition
  • Use the brand blue scale for icon fills
  • Scale icons uniformly (lock aspect ratio)
Don't
  • Pinch, stretch, or otherwise distort an icon
  • Mix arbitrary colors outside the palette
  • Add drop shadows, reflections, or rotation
  • Fill an outlined icon or outline a filled one

Brand mark

The "gable" — a peaked roofline silhouette — is the brand's signature framing device. It houses the wordmark, clips photography, and appears as ambient decoration. It should frame content, not compete with it.

LOWE'S
Note: this is a generic CSS reproduction of the documented silhouette for UI chrome (nav lockups, etc.) — swap in the official vector logo file for any customer-facing or trademark-sensitive placement.
  • Always pair with sufficient padding — never crowd the gable with text or other shapes.
  • Never stretch, tilt, or apply a stroke/outline to the gable.
  • Can be rotated 90° only when used purely as an image-clipping mask.

Using the tokens

Every value in this system lives in tokens/tokens.css (CSS custom properties) and tokens/tokens.json (portable export for Figma / Style Dictionary / other tooling). Components never hard-code a color, size, or radius — they reference a token.

<link rel="stylesheet" href="tokens/tokens.css" />
<link rel="stylesheet" href="css/fonts.css" />
<link rel="stylesheet" href="css/base.css" />
